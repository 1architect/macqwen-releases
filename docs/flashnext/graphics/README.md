# FlashNext graphics

These files illustrate the measurements in [`../research.md`](../research.md).

| File | Content |
|---|---|
| [`tokentrace/token-trace.html`](tokentrace/token-trace.html) | Interactive token-trace view |

capture overhead makes it unsuitable for absolute timing claims.
